웹 코딩 입문 가이드: HTML, CSS, JavaScript

프론트엔드 개발의 기초가 되는 뼈대, 디자인, 동적 기능을 직접 코드를 확인하고 체험하며 배워보세요!

HTML (뼈대) CSS (디자인) JavaScript (동작)

01. HTML (웹페이지의 뼈대 잡기)

1. 제목 만들기 (Heading 태그)

<h1>가장 큰 제목이에요</h1>
<h3>조금 작은 중간 제목이에요</h3>

가장 큰 제목이에요

조금 작은 중간 제목이에요

2. 글 작성과 강조하기 (Paragraph & Strong)

<p>일반적인 문장을 쓰는 공간입니다.</p>
<p><strong>중요한 글자는 굵게 표시해요!</strong></p>

일반적인 문장을 쓰는 공간입니다.

중요한 글자는 굵게 표시해요!

3. 누를 수 있는 버튼 만들기 (Button 태그)

<button class="sys-btn">클릭 버튼</button>

4. 목록 나열하기 (Unordered List 태그)

<ul>
  <li>첫 번째 항목</li>
  <li>두 번째 항목</li>
</ul>
  • 첫 번째 항목
  • 두 번째 항목

5. 다른 페이지로 이동하는 링크 (Anchor 태그)

<a href="#">여기를 눌러 이동하기</a>
여기를 눌러 이동하기

02. CSS (웹페이지 디자인 꾸미기)

1. 배경색 바꾸기와 모서리 둥글게 하기

.box {
  background-color: #1e293b;
  border-radius: 8px;
}
색상과 둥근 모서리가 적용된 상자

2. 여백과 테두리 다루기 (Box Model)

.model {
  padding: 12px;
  border: 3px solid #38bdf8;
}
테두리와 안쪽 여백이 있는 상자

3. 마우스 올렸을 때 변화 주기 (Hover 효과)

.card:hover {
  background-color: #38bdf8;
  transform: translateY(-2px);
}
여기에 마우스를 올려보세요!

4. 상자들을 나란히 정렬하기 (Flexbox)

.container {
  display: flex;
  gap: 8px;
}
상자 1
상자 2
상자 3

5. 글자 색상과 크기 다루기

.text {
  color: #38bdf8;
  font-size: 1.1rem;
  font-weight: bold;
}
색상과 크기가 바뀐 글자

03. JavaScript (웹페이지에 움직이는 기능 넣기)

1. 버튼을 누르면 글자 바꾸기

const el = document.getElementById('target1');
el.textContent = '글자가 변경되었습니다!';

바뀌기 전 기본 글자입니다.

2. 버튼을 누르면 상자 색상 바꾸기

const box = document.getElementById('targetBox');
box.style.backgroundColor = '#38bdf8';
색상이 변하는 상자

3. 클릭할 때마다 숫자가 커지는 카운터

let count = 0;
count++; // 숫자를 1씩 증가시킵니다.

현재 숫자: 0

4. 상자를 숨겼다 나타나게 하기 (토글)

if (elem.style.display === 'none') {
  elem.style.display = 'block';
}
사라졌다 나타나는 상자

5. 입력창에 쓴 글자가 실시간으로 나타나기

inputElem.oninput = (e) => {
  outputElem.textContent = e.target.value;
};
